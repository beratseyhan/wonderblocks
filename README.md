# WonderBlocks website

Support and privacy policy pages of the WonderBlocks iOS game, in English and Turkish, served by GitHub Pages at
https://beratseyhan.github.io/wonderblocks/.

| Page | English | Turkish |
|---|---|---|
| Home | `index.html` | `index-tr.html` |
| Support | `support.html` | `support-tr.html` |
| Privacy Policy | `privacy.html` | `privacy-tr.html` |

The pages are generated by `Marketing/Website/build_site.py` in the game project; edit the texts there and rebuild.
